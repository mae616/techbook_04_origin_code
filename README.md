## 使い方

1. このリポジトリをクローンまたはダウンロードします
2. 本文の手順のとおり、章のフォルダに移ってからコマンドを実行します
   - ページを配る: `python3 -m http.server 3000`（Python 3）
   - API などのサーバー: `node server.js`（Node.js）
   - 第3章だけは、本文で書き足していく `server.js` を、ステップごとに `api/step1.js`〜`api/step5.js` として置いています。本文の `node server.js` は、`api` フォルダで `node step1.js` のように、いま読んでいるステップのファイル名に読み替えてください
3. Chrome で `http://localhost:3000/` などを開きます

この巻はオリジン（スキーム・ホスト・ポート）の実験です。HTML ファイルをダブルクリックして開くのではなく、必ずサーバーを動かして `http://localhost:…` で開いてください。ポートの番号（3000、3001、4000 など）も本文と同じにしてください。番号が変わると、結果も変わります。

## Python 3 を用意する

ターミナル（Windows では PowerShell）で、次を実行します。

```
python3 --version
```

`Python 3.x.x` のように表示されれば、そのまま使えます。

### Mac

- 初めて `python3` を実行したとき、「コマンドライン・デベロッパツール」を入れるよう案内が出ることがあります。案内に従って入れると、`python3` が使えるようになります。
- 案内が出ないときや、新しい版を使いたいときは、公式サイト https://www.python.org/downloads/ から入れます。

### Windows

- 公式サイト https://www.python.org/downloads/ から入れます。インストールの最初の画面で「Add python.exe to PATH」にチェックを入れてください。
- Windows では、コマンドの名前が `python3` ではなく `python` か `py` になることがあります。本文の `python3 -m http.server 3000` は、次のどちらかに読み替えてください。

```
python -m http.server 3000
py -m http.server 3000
```

## Node.js を用意する

```
node --version
```

`v24.x.x` 以降が表示されれば使えます。入っていなければ、公式サイト https://nodejs.org/ から LTS 版を入れてください。
